# 🐹⚔️ CapySouls — The Rodent of Despair

A lightweight browser-based Souls-like game where you play as a capybara fighting for survival.

## 🎮 Play Now

👉 https://ShivankXD.github.io/capysouls/

(No installation required — runs directly in your browser)

---

## 🕹️ Controls

* **WASD / Arrow Keys** → Move
* **J / Z** → Attack
* **K / X** → Dodge Roll

---

## ⚔️ Features

* Stamina-based combat system
* Dodge roll with invincibility frames
* Enemy AI (grunt, brute, fast type)
* Health & stamina HUD
* Victory & death states
* Smooth browser gameplay (HTML5 Canvas)

---

## 🚀 Tech Stack

* HTML5
* JavaScript
* Canvas API

---

## 📦 How to Run Locally

1. Download or clone the repo
2. Open `index.html` in your browser

That’s it.
